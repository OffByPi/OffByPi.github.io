Notes on Obsidian-flavored markdown syntax I keep forgetting.

## Aliased links

Set a custom label instead of showing the filename with a pipe:

```markdown
[[filename|Label to show]]
```

Works with headings and blocks too:

```markdown
[[filename#Heading|Label to show]]
```
